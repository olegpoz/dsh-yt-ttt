# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-10

Первая публичная версия.

### Добавлено

- Бейдж в рельсе сайдбара: суммарно списанное за сегодня время, зелёный при достижении дневной цели.
- Панель за сегодня и вчера: итоги, список записей, шкала дня, дополненная до рабочего интервала.
- Форма «Adding time»: ключ задачи с подсказкой, дата, событие календаря, начало, длительность, конец и комментарий.
- Удаление записи с подтверждением.
- Список встреч Яндекс.Календаря через CalDAV и подстановка события в новую запись.
- Закреплённая командная задача для быстрых списаний.
- Два окна настроек: поведение панели и подключения к Трекеру и Календарю.
- Настройка «Task list query» — запрос Трекера, которым форма ищет свои текущие задачи (по умолчанию незакрытые задачи на текущего пользователя, сортировка по обновлению).
- Проверка соединения с Трекером и Календарём.

### Безопасность

- Токен Трекера и пароль приложения Календаря хранятся в credential store профиля, а не в конфигурации и не в записи плагина.
- Секреты никогда не возвращаются в браузер: окно настроек знает только, задано значение или нет.
- Токен и пароль приложения Календаря не читаются из конфигурации плагина: значение, оставленное в YAML, игнорируется с предупреждением в лог.
- Профиль без credential store больше не получает секрет в JSON-запись плагина: окно настроек отвечает ошибкой `unavailable`.
- Значения, сохранённые старыми сборками, переносятся в хранилище и вычищаются из записи плагина.

### Исправлено

- Проверка подключения Календаря в роуте событий использовала сконфигурированный пароль вместо действующего, из-за чего календарь с паролем только в credential store выглядел неподключённым.
